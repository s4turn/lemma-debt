# Provenance

This is an independent project created for this workspace with AI-assisted coding and writing. Its JavaScript, HTML, CSS, campaign text, Canvas drawings, original pixel-grid character figures and portraits, SVG logo and emblem with original path-drawn letterforms, and oscillator-generated sound effects were created for this project. The game has no bundled third-party graphics, music, fonts, game files, frameworks, or runtime packages. Fonts come from the player's system. Python and Node.js are optional local tools, not bundled dependencies.

FreeSynd, its forks, SyndicatFX, and SDL documentation were consulted as background. Their code, executable files, game data, original maps, characters and audio are not included. The project is inspired by the broad idea of isometric squad tactics and is not represented as an authorized Syndicate product.
